# AQIDAH SCHOOLS OF CREED - Ulema Institutions: the Ḥalqa.
#
# The periodic "activity" of a jurist seat. Fired rarely by
# on_action/00_aqd_game_start.txt's aqd_halqa_pulse (monthly_country_pulse)
# for any Muslim realm that owns a seat and has at least one province
# where that seat sits and no ḥalqa is already running (one per province,
# first-come-first-serve; scripted_triggers/z_aqd_jurist_triggers.txt).
# No in-province madrasa count is required - a bare seat is enough.
#
# Pure flavour: the immediate picks a province, picks the madhhab
# (random_list among whichever madhhabs qualify in that province - flat/
# uniform, UNLESS exactly one of them owns strictly more of its own
# madrasas there than every other qualifier, in which case that leader
# gets a 3x-weighted, not guaranteed, edge - scripted_effects/
# z_aqd_jurist_effects.txt's aqd_halqa_compute_leader), classifies it
# (state / orthodox / heterodox / tolerated - see scripted_effects/
# z_aqd_jurist_effects.txt's aqd_halqa_dispatch), and applies a
# temporary province-wide z_aqd_halqa_* modifier plus one-shot effects.
# The single option just dismisses.
#
# Saved scopes do not survive trigger_event, so the immediate re-derives
# its own target - mirroring z_aqd_establishment.1 / z_aqd_exile.1. The
# event trigger re-checks aqd_country_has_any_halqa_ready so a same-tick
# change that invalidates every ready province suppresses the pop-up
# instead of showing an empty one.
# =====================================================================
