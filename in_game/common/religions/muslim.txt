# =====================================================================
# SYSTEM B - the Islamic religious_school slot repurposed to *aqidah*
# (schools of creed) only.
#
# Full-file override of the vanilla common/religions/muslim.txt. The
# ONLY change from vanilla is the religious_school = x whitelist of each
# block: the schools of jurisprudence (madhhab) and the Sufi-order
# schools are removed. Madhhab stays in vanilla sharia_law (see
# laws/z_aqd_sharia_law.txt); the Sufi orders are this mod's
# building-country system.
#
# din_i_ilahi_school is the one exception kept in the whitelist despite
# living in religious_schools/sufi.txt: it is not a tariqa/order (no
# building-country identity to hand off to) and vanilla's own
# is_sufi_school trigger (scripted_triggers/religion_triggers.txt)
# already agrees - it's excluded there too. It stays an aqidah choice
# for both Shia and Sunni, unlockable exactly as vanilla intends via
# has_global_variable = din_i_ilahi_founded (flavor_mug.1).
#
# ibadi_school is likewise evicted despite living in
# religious_schools/ibadi.txt: vanilla's is_jurisprudence_school trigger
# groups it with the madhhab keys, not a creed one, so it is structurally
# a fiqh school. Its modifier now lives on sharia_law's ibadi_policy (see
# laws/z_aqd_sharia_law.txt), and religious_schools/z_aqd_ibadi_aqidah.txt
# adds wahbi_school and azzaba_school in its place as Ibadism's actual
# schools of creed - both Wahbiyya, split by institutional form
# (Imamate vs. the Maghreb's scholarly-council azzaba system) rather
# than doctrine; see that file's header for the history.
#
# Ibadi's whitelist is wahbi_school and azzaba_school ONLY - the
# vanilla-inherited Ashari/Maturidi/Athari/Mutazili crossover options are
# deliberately dropped (see scripted_effects/z_aqd_migrate.txt for the
# cleanup of any Ibadi country/character already holding one).
#
# ICD does not touch this file. Loading this mod together with a mod
# that also overrides muslim.txt (e.g. The Persianate World) is
# last-wins and unsupported.
# =====================================================================

	religious_school = wahbi_school
	religious_school = azzaba_school

			add = 1.5
		}

			add = 1
		}
	}

}
