# =====================================================================
# AQIDAH SCHOOLS OF CREED - shared "who can fill a vacancy" eligibility.
#
# NINE concrete location-scoped triggers, one per madhhab, shared by BOTH
# features that pick a substitute madhhab to inherit a vacated
# institution: scripted_effects/z_aqd_seat_collapse_effects.txt's
# aqd_seat_collapse_find_vacuum_candidate (a seat lost to demographic
# collapse) and scripted_effects/z_aqd_crackdown_vacancy_effects.txt's
# aqd_crackdown_pick_vacancy_candidate (a seat lost to a crackdown,
# "let the 'Ulema decide" option). Deliberately a NEW, separate trigger
# from aqd_debate_seat_eligible_<X> (scripted_triggers/z_aqd_debate_
# triggers.txt), not a reuse of it - that one still needs its own
# aqd_seat_madhhab_not_heterodox_to_root_<X> line for the fiqh-debate
# feature, which vacancy-filling deliberately drops: per the user's own
# final rule, a candidate's standing with the ruler's own aqeedah has NO
# bearing on eligibility to fill a vacancy - the only two gates are "not
# the exact madhhab that was just removed" (checked by each caller
# itself, via its own numeric variable, not here) and "this candidate's
# own sect clears 25% of the affected province's population" (also
# checked by each caller, since it needs the vacancy's own province in
# scope, not available to a bare location-scoped trigger). This trigger
# is only the "in good standing" half: not currently under an active
# fatwa ban, crackdown eviction, or a rival's vindication in this same
# episode, and not itself a location mid-resolution in another Seat
# Collapse attempt (z_aqd_seat_collapse_pending / z_aqd_vacuum_fill_
# pending, main_menu/common/static_modifiers/).
# =====================================================================
