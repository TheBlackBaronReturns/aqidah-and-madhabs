# aqd_fatwa_core_conditions: is root right now the attacker-leader of a
# war against a fellow-sect Muslim state, fought on a weak/absent casus
# belli, that root is clearly winning, whose madhhab root's own aqidah
# does not consider heretical? Deliberately carries NO cooldown and NO
# war_exhaustion threshold - those differ per stage and belong on each
# stage's own event trigger / pulse, not here: a shared cooldown here
# would make the escalation event's eligibility window impossible,
# since stage 2 can only fire strictly inside stage 1's own cooldown
# period.
#
# attacker_leader (not is_an_attacker): this feature is specifically
# about the country that DECLARED the war, not every ally who later
# joined the attacking side - attacker_leader is the single instigating
# country, matching that intent exactly. Mirrors events/religion/
# hindu_events.txt's attacker_leader / defender_leader pairing.
#
# war_score_versus (not war_score_in_war): avoids an ambiguous `war =`
# scope reference entirely by comparing two countries directly -
# confirmed idiom, e.g. events/disaster/decline_of_mali.txt's
# `any_attacker = { war_score_versus = { target = root ... } } }`
# (mirrored below with attacker/defender swapped, since root is the
# attacker here, not the defender).
#
# "Weak or lacking justification" = is_no_cb_war (cb_none - literally no
# CB at all) OR one of a hand-picked list of CBs that require nothing
# but rivalry/enemy-status/a flimsy pretext to use, no real claim, core,
# religious tie, or historical/situational grounding (common/casus_belli/
# *.txt, base game). Checked directly against every candidate file
# there is no base-game "opportunistic" tag to key off (confirmed by an
# exhaustive grep for custom_tags across that whole folder - none are
# actually set anywhere). Deliberately excludes cb_conquer_province
# (requires an actual is_core_of claim), cb_hegemon/_ultimatum (a
# systemic check on hegemonic power, not unilateral opportunism), and
# cb_cut_down_in_size (create_enabled = always = no - never a real
# player declare-war choice) - those read as legitimate-enough
# grounds even against a fellow Muslim. The ~50 remaining CBs (HRE,
# steppe/horde, colonial, native, and country/situation-specific ones)
# were not individually audited - none of them can realistically target
# a fellow-sect, aqidah-acceptable Muslim state in the first place, so
# they never reach this trigger regardless.
aqd_fatwa_core_conditions = {
	religion.group = religion_group:muslim
	aqd_country_owns_any_jurist_seat = yes
	any_current_war = {
		attacker_leader = root
		OR = {
			is_no_cb_war = yes
			NOT = { has_casus_belli = yes }
			casus_belli ?= casus_belli:cb_fabricated_conquer_province
			casus_belli ?= casus_belli:cb_trade_conflict
			casus_belli ?= casus_belli:cb_disrupting_trade
			casus_belli ?= casus_belli:cb_humiliate_rival
			casus_belli ?= casus_belli:cb_humiliate
			casus_belli ?= casus_belli:cb_conquer_enemy
			casus_belli ?= casus_belli:attack_threat
			casus_belli ?= casus_belli:cb_imperialism
		}
		defender_leader = {
			religion = root.religion
			aqd_madhhab_acceptable_to_root = yes
			war_score_versus = { target = root  value <= -0.25 }
		}
	}
}

# excluding a location currently carrying z_aqd_jurist_evicted_<X> - a
