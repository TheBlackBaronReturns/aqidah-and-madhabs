# ---------------------------------------------------------------------
# aqd_decline_attempt: called from on_action/00_aqd_game_start.txt's
# aqd_decline_pulse, country scope, only after the cheap aqd_country_has_
# any_declining_seat prefilter (scripted_triggers/z_aqd_decline_triggers.
# txt) already passed and the pulse's own random = { chance = N } already
# rolled a hit.
#
# PASS 1 - cache all 9 aqidah-compatibility verdicts once, at country
# scope, before ever touching a location. var:aqd_jurist_compat
# (scripted_effects/z_aqd_jurist_effects.txt's aqd_classify_madhhab_
# compatibility) depends only on root's own religious_school and the
# madhhab index - never on which location is being examined - so
# recomputing it inside a per-location scan would silently redo the same
# 9 verdicts once per candidate location for nothing. Cached into 9
# dedicated country variables so the per-location scan below can read
# them as plain triggers.
#
# PASS 1b - for each madhhab the compat verdict didn't already exclude
# (compat = -1 is a dead end regardless, so its probe is skipped - see
# aqd_decline_target_exists_check's own header below), cache whether a
# bordering realm exists RIGHT NOW that could actually receive that
# madhhab's departing jurists (aqd_decline_target_exists_check, reusing
# aqd_decline_migration_pick's own PASS 2 host criteria). This is what
# gates "let them go" behind a real destination existing BEFORE z_aqd_
# decline.1 ever fires, instead of destroying the seat first and only
# then discovering aqd_decline_migration_pick found nobody. Cached into 9
# dedicated country variables, same shape as PASS 1's compat cache.
#
# PASS 2 - pick ONE owned location uniformly among those holding at
# least one currently-eligible declining seat, via random_owned_location
# (same idiom as z_aqd_seat_collapse_effects.txt's aqd_seat_collapse_
# pick) - deliberately compatibility- and target-AGNOSTIC at this stage
# (aqd_declining_seat_present has neither check baked in - see that
# trigger family's own header for why).
#
# PASS 3 - Algorithm-R reservoir tie-break across however many madhhabs
# at THIS location independently qualify (mirrors aqd_seat_collapse_
# pick's own per-location madhhab tie-break exactly), now filtering by
# BOTH the pass-1 cached compatibility verdict AND the pass-1b cached
# target-existence verdict per candidate: only an orthodox/neutral madhhab
# (never -1, opposed/heterodox) WITH a real destination enters the
# reservoir. If the location pass 2 picked turns out to hold only a
# heterodox candidate, or one whose own madhhab currently has nowhere to
# migrate to (the umbrella OR let both through, but the real per-branch
# filters here exclude them), the reservoir simply ends up empty and this
# tick quietly does nothing - same "no candidate found" no-op behavior
# as aqd_seat_collapse_find_vacuum_candidate elsewhere in this mod; the
# monthly pulse just tries again next month.
#
# RESIDUAL RACE - this only guarantees a target existed at PICK time.
# z_aqd_decline.1's own "let them go" option still runs a fresh two-pass
# search of its own (aqd_decline_migration_pick) at RESOLUTION time, 1 day
# later; a target could in principle disappear in that window (same
# narrow-window class as aqd_decline_seat_still_present's own re-check on
# the seat side, scripted_triggers/z_aqd_decline_triggers.txt). Left
# unhandled deliberately, same as that trigger's own precedent - the seat
# would already be destroyed with nowhere for the jurists to land, but
# this is now a rare race rather than the routine case it was before this
# gate existed.
#
# HANDOFF - saved scopes do not survive trigger_event (confirmed
# repeatedly elsewhere in this mod - aqd_can_host_exile_seat's header,
# aqd_crackdown_exile_pick's "scope:aqd_exile_target is transient"
# comment, and Seat Collapse's own z_aqd_seat_collapse_pending marker).
# So the winning location gets a disposable z_aqd_decline_pending marker
# (1 month, main_menu/common/static_modifiers/z_aqd_decline_pending.txt)
# instead of relying on the scope itself; var:aqd_decline_madhhab (a
# plain country variable) DOES survive trigger_event and is the actual
# handoff z_aqd_decline.1 reads (trigger = { has_variable = aqd_decline_
# madhhab }). on_action/00_aqd_game_start.txt's aqd_decline_pulse also
# guards NOT = { has_variable = aqd_decline_madhhab } so this effect is
# never re-entered while a previous pick is still in flight (the 1-day
# gap between the pick and z_aqd_decline.1 actually firing).
# ---------------------------------------------------------------------

# ---------------------------------------------------------------------
# TARGET-EXISTENCE PROBE - aqd_decline_target_exists_check = { MADHHAB
# SECT }: does at least one bordering realm exist right now that could
# receive $MADHHAB$'s departing jurists? Used by aqd_decline_attempt's
# own PASS 1b (above it in file order, below it in read order - Paradox
# script has no forward-declare ordering requirement) to keep a madhhab
# with nowhere to go OUT of the PASS 3 reservoir entirely, instead of
# picking it and only discovering the dead end after the seat is already
# destroyed. This is a scripted_effect, not a scripted_trigger - the
# parameterised aqd_can_host_exile_seat call inside it only substitutes
# correctly from an effect context (scripted_triggers/z_aqd_jurist_
# triggers.txt's own header). Reuses aqd_decline_migration_pick's PASS 2
# criteria only (drops the "state madhhab already matches" requirement) -
# PASS 2 is a strict superset of PASS 1, so "does PASS 2 find anyone" is
# exactly "does an eligible target exist at all", without needing to
# replicate both passes here.
#
# any_country, not random_country: this is a pure existence question,
# not a pick, so there is no need to build the full random-selection
# pool random_country requires before choosing - any_country is a
# genuine boolean iterator (confirmed vanilla idiom, e.g. common/
# scripted_triggers/country_triggers.txt's is_in_defensive_war and
# generic_actions/D008_lutheran.txt's ai_will_do) that reads true as soon
# as ONE candidate matches, so it never scans past the first hit. It is
# still a built-in engine iterator, not a mod-defined scripted_trigger,
# so nesting the parameterised aqd_can_host_exile_seat inside it from
# this scripted_effect's own if/limit carries the exact same $PARAM$-
# substitution safety as random_country's identical nesting in aqd_
# decline_migration_pick below - the documented gotcha (scripted_
# triggers/z_aqd_jurist_triggers.txt's own header) is specifically about
# a PARAMETERISED scripted_trigger invoked from inside ANOTHER scripted_
# trigger; neither side of this nesting is one.
#
# The short-circuit only pays off when a target DOES exist - the one
# case this probe exists to rule OUT (no target anywhere) still has to
# scan every candidate before concluding that, exactly as random_country
# would have. The saving is real (most declining seats have an eligible
# neighbour most of the time), just not in the specific failure case this
# feature was built to catch.
#
# Output: var:aqd_decline_has_target (0/1), read by the caller
# immediately after each wrapper call, then copied into a dedicated
# per-madhhab variable before the next call overwrites it - same single-
# slot transient-output idiom aqd_decline_attempt's own PASS 1 already
# uses for var:aqd_jurist_compat.
# ---------------------------------------------------------------------
aqd_decline_target_exists_check = {
	if = {
		limit = {
			any_country = {
				NOT = { this = root }
				religion = religion:$SECT$
				has_policy = sharia_law_policy
				is_neighbor_of_country_or_across_one_seazone = root
				aqd_can_host_exile_seat = { MADHHAB = $MADHHAB$  SECT = $SECT$ }
			}
		}
		set_variable = { name = aqd_decline_has_target  value = 1 }
	}
	else = {
		set_variable = { name = aqd_decline_has_target  value = 0 }
	}
}

# Two-pass weighted neighbour selection, run at the departing country's
# own scope (root - safe here, unlike aqd_crackdown_exile_pick's own
# scope:aqd_crackdown_country stand-in, since this is only ever called
# from z_aqd_decline.1's own option, a plain country_event where root is
# reliable, never from inside a generic_action). Mirrors aqd_crackdown_
# exile_pick (z_aqd_jurist_effects.txt) exactly: pass 1 (70%) prefers a
# bordering realm whose own official madhhab already matches the
# departing school; pass 2 falls back to any eligible bordering realm.
# "Bordering" = a land border OR across a single sea zone (is_neighbor_
# of_country_or_across_one_seazone, an engine trigger). EXPLICITLY-
# ACCEPTED behavior change from reusing aqd_can_host_exile_seat as the
# host-eligibility check: the old aqd_is_eligible_jurist_source (removed)
# also required root.<X>_institution_tier < 3 and NOT root has_policy =
# <X>_policy ("never offer your own madhhab as foreign"). Neither is
# reproduced here, deliberately - z_aqd_exile.1's own target-pick doesn't
# have them either, and the whole point of this rework is to give
# "Foreign Jurists at the Gate" the same target-selection semantics as
# its already-shipped sibling, including pass 1's explicit preference for
# a candidate whose own state madhhab ALREADY MATCHES the departing
# school - exactly the "weighted towards state madhhab" behavior this
# feature asks for. aqd_can_host_exile_seat additionally requires
# religion = religion:$SECT$ (the candidate's own STATE religion, not
# just religion group), so a Sunni realm can no longer receive migrating
# Shia jurists this way - also intentional, matching exile's existing
# behavior exactly.
aqd_decline_migration_pick = {
	random = {
		chance = 70
		random_country = {
			limit = {
				NOT = { this = root }
				religion = religion:$SECT$
				has_policy = sharia_law_policy
				has_policy = $MADHHAB$_policy
				is_neighbor_of_country_or_across_one_seazone = root
				aqd_can_host_exile_seat = { MADHHAB = $MADHHAB$  SECT = $SECT$ }
			}
			save_scope_as = aqd_jurists_target
		}
	}
	if = {
		limit = { NOT = { exists = scope:aqd_jurists_target } }
		random_country = {
			limit = {
				NOT = { this = root }
				religion = religion:$SECT$
				has_policy = sharia_law_policy
				is_neighbor_of_country_or_across_one_seazone = root
				aqd_can_host_exile_seat = { MADHHAB = $MADHHAB$  SECT = $SECT$ }
			}
			save_scope_as = aqd_jurists_target
		}
	}
	if = {
		limit = { exists = scope:aqd_jurists_target }
		scope:aqd_jurists_target = {
			set_variable = { name = aqd_jurists_madhhab  value = $IDX$ }
			trigger_event_non_silently = { id = z_aqd_jurists.1  days = 3 }
		}
	}
}
