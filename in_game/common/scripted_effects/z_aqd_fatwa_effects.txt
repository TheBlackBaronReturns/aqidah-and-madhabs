# aqd_fatwa_evaluate_seat_demand = { MADHHAB }: given the canonical 1-9
# index of exactly which seat is being asked, answers "does the WAR'S
# DEFENDANT resonate with this seat's own madhhab enough that it demands
# the ruler stop fighting them?" - deliberately NOT the same question the
# jihad fatwa asks of the SAME shared engine (root's own approval,
# read straight). Requires scope:enemy (the war's defendant, found by
# aqd_fatwa_attempt_stage1 below for stage 1, or already live from z_aqd_
# fatwa.2's own immediate for stage 2 - see that event's header) to
# already be a valid saved scope; if it is not, this seat simply stays
# quiet (var:aqd_madhhab_approval_result = 0) rather than erroring - a
# real, already-hit failure mode per z_aqd_fatwa_events.txt's own header
# (a debug force-fire, or any other path that reaches this call with no
# resolvable war/defendant).
#
# Deliberately does NOT call aqd_compute_seat_approval (scripted_effects/
# z_aqd_madhhab_approval_effects.txt) - that helper, and the aqd_madhhab_
# approval_<X> script_values it evaluates (script_values/z_aqd_madhhab_
# approval.txt), are shared with three OTHER root-anchored features
# (jihad fatwa, crackdown-vacancy, seat-collapse) that must stay
# untouched, root-only, exactly as they are today. Everything here is
# self-contained instead: aqd_classify_seat_compatibility is called with
# COUNTRY = scope:enemy (not root) - so var:aqd_seat_compat now answers
# "does the DEFENDANT's own aqidah consider this seat's madhhab favored/
# neutral/opposed" - and the matching aqd_madhhab_approval_<X> script_
# value is evaluated with scope:enemy as the CURRENT scope, so its bare
# societal_value:/has_policy=/modifier:tolerance_own references all
# naturally resolve against the defendant too. The whole judgment is
# thereby one consistent question about one country, never a mix of
# root and the defendant.
#
# $MADHHAB$ is either a literal (stage 2's per-madhhab loop in z_aqd_
# fatwa_events.txt) or var:aqd_fatwa_seat_madhhab, which lives on ROOT
# (stage 1, via aqd_fatwa_attempt_stage1). $PARAM$ substitution is purely
# textual, so using that raw token directly inside scope:enemy = {...}
# would - for the variable-reference form - incorrectly look for it on
# the defendant instead of root. The first line below resolves it into a
# real, always-root-anchored variable first (mirroring the original
# code's own root = {...} wrapping for the identical reason), then
# relays its value onto scope:enemy's own copy via the confirmed value =
# root.var:X cross-scope idiom (common/scripted_effects/religious_
# effects.txt:288-295, among others) - safe regardless of whether the
# original $MADHHAB$ argument was a literal or a variable reference.
#
# scope:enemy is guaranteed to be "a fellow-sect Muslim state" by aqd_
# fatwa_core_conditions (scripted_triggers/z_aqd_fatwa_triggers.txt), so
# it can legitimately be mid-running its OWN crackdown-vacancy or seat-
# collapse computation using these exact same variable names at the same
# moment. Every variable borrowed on its scope is therefore saved (only
# if it already existed) before use and restored (or removed, if it
# didn't) afterward - the same save/restore idiom aqd_classify_seat_
# compatibility itself already uses for aqd_compat_madhhab/aqd_jurist_
# compat, applied here to avoid clobbering state that isn't this
# feature's to touch.
#
# No inversion (contrast the old aqd_invert_approval_scratch, now
# deleted as dead code): high resonance between the defendant and this
# seat's own character IS the bless-probability input directly, not
# something to invert. Leaves var:aqd_madhhab_approval_result readable
# at root (1 = this seat steps up to demand peace, 0 = it stays quiet).
# ---------------------------------------------------------------------
aqd_fatwa_evaluate_seat_demand = {
	if = {
		limit = { NOT = { exists = scope:enemy } }
		root = { set_variable = { name = aqd_madhhab_approval_result  value = 0 } }
	}
	else = {
		root = { set_variable = { name = aqd_seat_madhhab  value = $MADHHAB$ } }
		scope:enemy = {
			if = { limit = { exists = var:aqd_seat_madhhab }     set_variable = { name = aqd_seat_madhhab_save     value = var:aqd_seat_madhhab } }
			if = { limit = { exists = var:aqd_seat_compat }      set_variable = { name = aqd_seat_compat_save      value = var:aqd_seat_compat } }
			if = { limit = { exists = var:aqd_approval_scratch } set_variable = { name = aqd_approval_scratch_save value = var:aqd_approval_scratch } }
			set_variable = { name = aqd_seat_madhhab  value = root.var:aqd_seat_madhhab }
		}
		aqd_classify_seat_compatibility = { COUNTRY = scope:enemy  SEAT_MADHHAB = var:aqd_seat_madhhab }
		if      = { limit = { scope:enemy = { var:aqd_seat_madhhab = 1 } }  scope:enemy = { set_variable = { name = aqd_approval_scratch  value = aqd_madhhab_approval_hanafi } } }
		else_if = { limit = { scope:enemy = { var:aqd_seat_madhhab = 2 } }  scope:enemy = { set_variable = { name = aqd_approval_scratch  value = aqd_madhhab_approval_hanbali } } }
		else_if = { limit = { scope:enemy = { var:aqd_seat_madhhab = 3 } }  scope:enemy = { set_variable = { name = aqd_approval_scratch  value = aqd_madhhab_approval_maliki } } }
		else_if = { limit = { scope:enemy = { var:aqd_seat_madhhab = 4 } }  scope:enemy = { set_variable = { name = aqd_approval_scratch  value = aqd_madhhab_approval_shafii } } }
		else_if = { limit = { scope:enemy = { var:aqd_seat_madhhab = 5 } }  scope:enemy = { set_variable = { name = aqd_approval_scratch  value = aqd_madhhab_approval_zahiri } } }
		else_if = { limit = { scope:enemy = { var:aqd_seat_madhhab = 6 } }  scope:enemy = { set_variable = { name = aqd_approval_scratch  value = aqd_madhhab_approval_ismaili } } }
		else_if = { limit = { scope:enemy = { var:aqd_seat_madhhab = 7 } }  scope:enemy = { set_variable = { name = aqd_approval_scratch  value = aqd_madhhab_approval_jafari } } }
		else_if = { limit = { scope:enemy = { var:aqd_seat_madhhab = 8 } }  scope:enemy = { set_variable = { name = aqd_approval_scratch  value = aqd_madhhab_approval_zaidi } } }
		else_if = { limit = { scope:enemy = { var:aqd_seat_madhhab = 9 } }  scope:enemy = { set_variable = { name = aqd_approval_scratch  value = aqd_madhhab_approval_ibadi } } }
		root = {
			set_variable = { name = aqd_approval_scratch  value = scope:enemy.var:aqd_approval_scratch }
			aqd_roll_approval_percentage = yes
			remove_variable = aqd_seat_madhhab
		}
		scope:enemy = {
			if   = { limit = { exists = var:aqd_seat_madhhab_save }     set_variable = { name = aqd_seat_madhhab  value = var:aqd_seat_madhhab_save }     remove_variable = aqd_seat_madhhab_save }
			else = { remove_variable = aqd_seat_madhhab }
			if   = { limit = { exists = var:aqd_seat_compat_save }      set_variable = { name = aqd_seat_compat  value = var:aqd_seat_compat_save }      remove_variable = aqd_seat_compat_save }
			else = { remove_variable = aqd_seat_compat }
			if   = { limit = { exists = var:aqd_approval_scratch_save } set_variable = { name = aqd_approval_scratch  value = var:aqd_approval_scratch_save } remove_variable = aqd_approval_scratch_save }
			else = { remove_variable = aqd_approval_scratch }
		}
	}
}

# 9-branch dispatch, same shape and same reasoning as scripted_effects/
# z_aqd_jihad_fatwa_effects.txt's aqd_jihad_fatwa_stamp_declined_for_seat:
# stamps z_aqd_fatwa_declined_<X> (main_menu/common/static_modifiers/
# z_aqd_fatwa_declined.txt) on the SPECIFIC seat that just declined stage
# 1, reading root's var:aqd_fatwa_seat_madhhab rather than re-deriving
# from has_building for the same multi-seat-location reason. Called from
# aqd_fatwa_attempt_stage1's own decline branch, at scope:target_location,
# BEFORE that variable is cleaned up. years = 50 is a safety-net duration
# only - the marker is always cleared explicitly once the unjust-war
# episode ends (on_action/00_aqd_game_start.txt's aqd_fatwa_episode_
# cleanup_pulse). This is the "one shot per war" fix: previously a
# decline cost this seat nothing, so the very next month's pulse could -
# and eventually, given a long enough war, would - pick it again, making
# eventual success for SOME seat in the realm a near-certainty regardless
# of how low any individual seat's own approval score was.
aqd_fatwa_stamp_declined_for_seat = {
	if      = { limit = { root = { var:aqd_fatwa_seat_madhhab = 1 } }  add_location_modifier = { modifier = z_aqd_fatwa_declined_hanafi   years = 50  mode = add_and_extend } }
	else_if = { limit = { root = { var:aqd_fatwa_seat_madhhab = 2 } }  add_location_modifier = { modifier = z_aqd_fatwa_declined_hanbali  years = 50  mode = add_and_extend } }

# ---------------------------------------------------------------------
# aqd_fatwa_attempt_stage1: country-scoped, called from the pulse's
# effect (on_action/00_aqd_game_start.txt's aqd_fatwa_pulse), NOT from an
# event - the silent-miss design mirrors the jihad fatwa's own aqd_jihad_
# fatwa_attempt exactly. The full aqd_fatwa_core_conditions is checked
# here (not just the pulse's own cheap prefilter) since there is no
# event trigger left to lean on before deciding whether to pop anything;
# z_aqd_fatwa.1's own trigger still re-checks it a second time at fire
# time as a defensive re-validation, same as before this change.
#
# Finds and saves scope:enemy (the war's defendant) BEFORE picking a seat
# or rolling - aqd_fatwa_evaluate_seat_demand's own approval computation
# now depends entirely on the defendant, unlike before this change, when
# only the LATER event's flavor text needed it. Byte-for-byte the same
# any_current_war/defender_leader condition set as aqd_fatwa_core_
# conditions's own check just above (this file's own header notes it is
# deliberately re-checked, not reused, since a saved scope from a trigger
# context does not carry over) and as both z_aqd_fatwa.1's and z_aqd_
# fatwa.2's own immediate in events/religion/z_aqd_fatwa_events.txt - all
# three MUST be kept in sync if this condition set ever changes, there is
# no compiler link enforcing it. A missing enemy here nests the rest of
# this block behind exists = scope:enemy and does nothing further this
# month (aqd_fatwa_pick_seat, which sets var:aqd_fatwa_seat_madhhab,
# never runs on that path, so there is nothing to clean up) - a true
# silent no-op, not a wasted decline that would needlessly burn a seat's
# one-shot-per-war slot over what is really a structural edge case (see
# aqd_fatwa_evaluate_seat_demand's own header for why this same class of
# failure is handled differently - and still safely - for stage 2's
# caller, which cannot use this same outer-guard shape).
#
# Feeds aqd_fatwa_pick_seat's resolved var:aqd_fatwa_seat_madhhab
# straight into aqd_fatwa_evaluate_seat_demand's $MADHHAB$ parameter -
# this variable, unlike a saved scope, survives the trigger_event below,
# so z_aqd_fatwa.1's own refuse option can apply the ban to the correct
# specific seat instead of re-guessing from has_building.
# ---------------------------------------------------------------------
aqd_fatwa_attempt_stage1 = {
	if = {
		limit = { aqd_fatwa_core_conditions = yes }
		random_current_war = {
			limit = {
				attacker_leader = root
				OR = {
					is_no_cb_war = yes
					NOT = { has_casus_belli = yes }
					casus_belli ?= casus_belli:cb_fabricated_conquer_province
					casus_belli ?= casus_belli:cb_trade_conflict
					casus_belli ?= casus_belli:cb_disrupting_trade
					casus_belli ?= casus_belli:cb_humiliate_rival
					casus_belli ?= casus_belli:cb_humiliate
					casus_belli ?= casus_belli:cb_conquer_enemy
					casus_belli ?= casus_belli:attack_threat
					casus_belli ?= casus_belli:cb_imperialism
				}
				defender_leader = {
					religion = root.religion
					aqd_madhhab_acceptable_to_root = yes
					war_score_versus = { target = root  value <= -0.25 }
				}
			}
			save_scope_as = target_war
		}
		if = {
			limit = { exists = scope:target_war }
			scope:target_war = { defender_leader = { save_scope_as = enemy } }
		}
		if = {
			limit = { exists = scope:enemy }
			aqd_fatwa_pick_seat = yes
			if = {
				limit = { exists = scope:target_location }
				scope:target_location = { aqd_fatwa_evaluate_seat_demand = { MADHHAB = var:aqd_fatwa_seat_madhhab } }
				if = {
					limit = { var:aqd_madhhab_approval_result = 1 }
					scope:target_location = { aqd_stamp_pending_pick = yes }
					trigger_event_non_silently = { id = z_aqd_fatwa.1  days = 1 }
				}
				else = {
					scope:target_location = { aqd_fatwa_stamp_declined_for_seat = yes }
					remove_variable = aqd_fatwa_seat_madhhab
				}
			}
		}
	}
	remove_variable = aqd_seat_madhhab
	remove_variable = aqd_seat_compat
	remove_variable = aqd_approval_scratch
	remove_variable = aqd_madhhab_approval_result
}

# aqd_fatwa_apply_displeased_for_seat = { MADHHAB  LOCATION }:
# given the canonical 1-9 index of exactly which seat to punish and the
# location to punish it at, applies that seat's ban. NO LONGER branches
# on has_building - a location can hold more than one seat, so re-
# deriving "which one" from building presence here could stamp the ban
# on an entirely different co-located madhhab than the one that actually
# refused (mirrors scripted_effects/z_aqd_jihad_fatwa_effects.txt's
# aqd_apply_fatwa_of_jihad_for_seat, fixed the same way for the same
# reason).
#
# MUST be called from a scope where a bare $MADHHAB$ resolves correctly
# - always root, for both call sites (events/religion/z_aqd_fatwa_events.
# txt's z_aqd_fatwa.1 refuse option passes its own var:aqd_fatwa_seat_
# madhhab directly since that option already runs at root by default;
# z_aqd_fatwa.2's refuse option is inside a location-scoped every_
# location_in_area loop, so IT wraps its own call in root = {...} and
# passes a literal 1-9 instead). NEVER call this from inside $LOCATION$
# = {...} itself - unlike a literal, $MADHHAB$ = var:aqd_fatwa_seat_
# madhhab needs the real root object to find the variable on, and this
# function does not root-wrap the comparison itself (it can't - the same
# $MADHHAB$ token also has to work for a bare literal, and wrapping a
# literal in root = { 3 = 1 } is meaningless). $LOCATION$ is a scope
# reference (e.g. scope:target_location, or a saved loop scope)
# re-entered only for the actual modifier calls below - confirmed-safe
# "pass a scope, re-enter via $PARAM$ = {}" idiom, mirrors aqd_classify_
# seat_compatibility's own $COUNTRY$ = {...} convention (scripted_
# effects/z_aqd_madhhab_approval_effects.txt).
#
# Per madhhab:
#   - applies/extends THAT location's own madhhab-specific fatwa ban to
#     a flat 12 years (main_menu/common/static_modifiers/
#     z_aqd_fatwa_displeased.txt) - both the initial stamp (stage 1
#     refuse) and any later re-extension (stage 2 refuse) use the same
#     12, via mode = add_and_extend, so a seat that gets re-angered never
#     ends up on a shorter or longer clock than one banned only once;
#   - clears ONLY that same madhhab's own currently-active ḥalqa (its 3
#     class-variant keys) - but PROVINCE-WIDE, at every owned location in
#     $LOCATION$'s own province, not just $LOCATION$ itself. A ḥalqa's
#     class modifier is stamped uniformly across every owned location of
#     its province by aqd_halqa_apply_state/_orthodox/_heterodox
#     (scripted_effects/z_aqd_jurist_effects.txt); clearing it only at
#     the seat's own location would strip the seat's own copy while
#     leaving every other location in the province still carrying (and
#     benefiting/suffering from) the now-repudiated circle for up to its
#     remaining 12 years. The ban itself stays LOCATION-scoped (its
#     unrest/production penalty is deliberately local to the seat that
#     was refused), only the ḥalqa cancellation is widened to match the
#     ḥalqa's own original footprint. Any OTHER madhhab's circle
#     elsewhere in (or sharing) the province is untouched - the fatwa is
#     madhhab-specific, so its consequences must be too.
# Deliberately NOT a 28-key blanket sweep (contrast
# zz_aqd_debug_effects.txt's aqd_debug_clear_halqa, which is fine for a
# debug reset but would be wrong here: wiping every madhhab's circle
# would undo the whole point of tracking these bans per-madhhab).
#
# Each of the 3 class-variant removals is gated behind its own
# has_location_modifier check - only ONE class is ever active for a given
# madhhab/location pair, so an unconditional trio would tooltip-preview
# all 3 as "removed" in the refuse option even though at most 1 ever is.
# ---------------------------------------------------------------------
aqd_fatwa_apply_displeased_for_seat = {
	if = {
		limit = { $MADHHAB$ = 1 }

			add_location_modifier = { modifier = z_aqd_fatwa_displeased_hanafi  years = 12  mode = add_and_extend }
