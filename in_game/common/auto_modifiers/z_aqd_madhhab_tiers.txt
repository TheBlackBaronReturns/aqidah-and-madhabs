# =====================================================================
# AQIDAH SCHOOLS OF CREED - Ulema Institutions: tiered national
# modifiers per madhhab (Presence / Noteworthy / Plurality /
# Predominance).
#
# Each block is gated by an exact match on <X>_institution_tier
# (script_values/z_aqd_madhhab_counts.txt): 1 Presence, 2 Noteworthy,
# 3 Plurality, 4 Predominance. That value already encodes everything -
#  - the share bands (0.15 / 0.35 / 0.60 of the realm's cached jurist
#    total: var:aqd_realm_jurist_total, seat 4 / madrasa 1),
#  - the seat floor (>= Presence while the madhhab holds any Seat),
#  - Predominance = the realm's OWN official sharia_law madhhab, alone
#    (has_policy sets tier 4 and so removes it from bands 1-3),
# so there is no OR/NOT has_policy clause here any more.
#
# A madhhab with no buildings that is not the state law is tier 0 and
# matches none of the four blocks - intentional, not a missing tier 0.
#
# The band edges live in script_values/z_aqd_madhhab_counts.txt. The
# realm total is cached and refreshed by aqd_recount_jurist_total /
# _pulse (on_action/00_aqd_game_start.txt). The crackdown's own
# tier-detection and half-strength cap live in scripted_effects/
# z_aqd_jurist_effects.txt; the foreign-jurist eligibility check
# (tier < 3 = below Plurality) in scripted_triggers/
# z_aqd_jurist_triggers.txt.
# =====================================================================
