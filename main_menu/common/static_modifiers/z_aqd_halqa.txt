# =====================================================================
# AQIDAH SCHOOLS OF CREED - Ulema Institutions: Ḥalqa modifiers.
#
# A ḥalqa (حلقة, a mudarris's teaching circle) is the periodic "activity"
# of a jurist seat - no in-province madrasa count required.
# events/religion/z_aqd_halqa_events.txt fires z_aqd_halqa.1, which
# stamps ONE of these on every owned location of the seat's province for
# ~12 years (scripted_effects/z_aqd_jurist_effects.txt's aqd_halqa_
# apply_*). Runs per madhhab, not once per province - a different
# madhhab's seat in the same province can have its own key from this
# file active at the same time (scripted_triggers/z_aqd_jurist_
# triggers.txt's aqd_halqa_prov_ready_<X> is what tracks each madhhab's
# own occupancy independently).
#
# NAMING: 27 concrete objects, one per (state/orthodox/heterodox) x (nine
# madhhabs) - z_aqd_halqa_<class>_<madhhab>, e.g. z_aqd_halqa_state_hanafi
# - so the display NAME always reads "<Madhhab> Madhhab Ḥalqa" (with
# base-game's own diacritics, main_menu/localization/english/
# religion_l_english.yml's hanafi_school etc.) regardless of whether that
# seat's circle is currently state/orthodox/heterodox for the observing
# realm - the CLASS distinction lives in the DESC text and the fields
# below, not the name. tolerated stays ONE madhhab-agnostic object
# (z_aqd_halqa_tolerated, unchanged) - a din-i-ilahi realm's circle reads
# "Ṣulḥ-i Kul" (Akbar's own term for the doctrine, not the placeholder
# "Tolerated") no matter which madhhab it is, since
# tolerated is about the OBSERVING realm's syncretism, not the seat's own
# school (see aqd_halqa_dispatch in z_aqd_jurist_effects.txt - din-i-ilahi
# is checked first and unconditionally, before madhhab ever matters).
#
# Each madhhab's own three class keys (state/orthodox/heterodox for that
# ONE madhhab) still double as ITS OWN one-ḥalqa-per-madhhab-per-province
# occupancy marker - no separate marker object was added (a location
# modifier with no gameplay fields would still render as its own row in
# the province panel's active-modifiers list - same one-icon-per-modifier
# behaviour confirmed for the four original class keys - so a fields-less
# marker would ADD a stray visible entry, not remove one). scripted_
# triggers/z_aqd_jurist_triggers.txt's aqd_halqa_prov_ready_<X> checks
# only that ONE madhhab's own three keys, not all 28 - a realm-wide 28-
# way "is ANY ḥalqa active anywhere" umbrella used to gate this instead
# (the now-removed aqd_location_has_active_halqa), which is what used to
# make every madhhab in a province mutually exclusive; per-madhhab
# checking is what lets different seats run their own circles in
# parallel.
#
# PER-MADHHAB TUNING: each madhhab's nine fields (three per class) are
# now genuinely different, grounded in that school's real history (see
# the per-madhhab notes below each block). scripted_effects/
# z_aqd_jurist_effects.txt's aqd_halqa_apply_state / _orthodox /
# _heterodox each pick which of the nine keys to add_location_modifier
# via a 9-way branch on var:aqd_halqa_madhhab (the canonical 1-9 index,
# already set before dispatch runs) - the KEYS themselves are unchanged
# by this tuning pass, only the field VALUES inside each definition
# below, so nothing outside this file needed to change. NOT every
# variant carries every field any more - see each madhhab's own note
# below for which fields it drops or gains (e.g. no local_unrest at all
# for z_aqd_halqa_state_zahiri / _orthodox_zahiri, no local_heretic_pop_
# conversion_speed_modifier for z_aqd_halqa_state_hanafi, no
# local_monthly_control at all - not even reduced - for any of the three
# Shāfiʿī variants). local_cultural_influence is now MĀLIKĪ-EXCLUSIVE -
# every other madhhab's three variants had it removed outright (per user
# instruction) rather than shared at a flat low value; only
# z_aqd_halqa_tolerated (not a madhhab) still keeps its own independent
# 0.05 copy. Every variant still carries local_clergy_max_literacy (down
# to a token 0.5 for all three Ismāʿīlī variants) and keeps it FIRST for
# the badge-icon experiment. Jaʿfarī is no longer a copy of Ḥanafī - see
# its own notes below for its now-independent hawza/marjaʿiyya-flavoured
# fields.
#
# CLASS baselines (what a madhhab keeps unless its own note below says
# otherwise) - see the dispatch in z_aqd_jurist_effects.txt:
#   state      - the seat's madhhab IS the realm's own sharia_law policy.
#                Consolidation: control, unrest down, heretic (cross-sect
#                Muslim, NOT heathen) conversion boosted specifically
#                (local_heretic_pop_conversion_speed_modifier). One-shot:
#                20%/10% (seat/rest of province) of cross-sect Muslims
#                convert to the state religion - same shape as
#                heterodox's own conversion, just aimed at root.religion.
#                Ḥanbalī and Ismāʿīlī double this to 30%/20% (scripted_
#                effects/z_aqd_jurist_effects.txt's aqd_halqa_apply_state).
#                TODO: local_monthly_control's 0.05 default is a
#                PLACEHOLDER - the user asked for this to mirror "the
#                parliament center modifier" (halved), but no building/
#                modifier by that name exists anywhere in base game or
#                this mod (confirmed by an exhaustive grep). Do not tune
#                the unmodified 0.05 default further without pinning
#                down the actual reference (several madhhabs below now
#                override it directly with their own explicit value).
#   orthodox   - the creed favours the madhhab, or is neutral to it
#                (var:aqd_jurist_compat 1 or 0). Calm + minor uplift +
#                a heretic conversion HALF of state's (10%/5%,
#                seat/rest). No societal-value nudge - a merely-tolerated
#                orthodoxy is deliberately neutral on that axis; only
#                heterodoxy still pushes it (toward humanism).
#   heterodox  - the creed opposes the madhhab (var:aqd_jurist_compat
#                -1). Raises unrest (a provocation, not a calming
#                presence); blocks clergy conversion outright (any
#                religion) and slows heretic (other-sect Muslim)
#                conversion 60%, leaving heathen conversion untouched;
#                literacy/cultural influence as orthodox.
#                One-shot (event-side, not this modifier): 20% of the
#                state-religion population converts to the seat's own
#                sect at the seat's own location, 10% elsewhere in the
#                province (30%/20% for Ḥanbalī/Ismāʿīlī, same as state -
#                scripted_effects/z_aqd_jurist_effects.txt's aqd_halqa_
#                apply_heterodox); a tiny nudge of the realm toward
#                humanism.
#                monthly_towards_humanist (the periodic societal-value
#                push) is country-scope-only (game_data category =
#                country) and so cannot live in this location modifier -
#                deliberately left a one-shot change_societal_value in
#                the event instead of a companion country modifier.
#   tolerated  - din-i-ilahi realms only. The orthodox uplift, but NO
#                conversion of any kind (the syncretic state proselytises
#                for none) and the heterodox conversion block.
#
# Modifier fields are all valid at location scope (category = location,
# confirmed against main_menu/common/modifier_type_definitions/
# 00_modifier_types.txt for every field used below, including
# local_tribal_promotion, local_population_growth, local_defensive,
# local_manpower_modifier, local_trade_center_power,
# local_clergy_estate_power and movement_cost (all
# percent = yes), local_max_literacy (already_percent = yes, same
# whole-number-as-percentage-points convention as local_clergy_max_
# literacy: a value of 3 there reads as "+3%", NOT 0.03), and
# local_monthly_development/local_frontage_allowed/local_cultural_
# influence (plain values, no percent flag - development takes small
# decimals like base game's own 0.0050, frontage takes small flat
# integers like base game's 10/3, cultural_influence's own normal-
# building range is 0.1-0.5 per culture_buildings.txt).
# local_cultural_influence replaces the earlier local_cultural_tradition
# on every madhhab (same field category/shape - no percent flag, plain
# location-scope value - so the swap is a pure rename, no rebalancing
# needed: every existing value, 0.02-0.1, already sits at or below the
# lowest tier (0.1) a dedicated normal culture_buildings.txt building
# grants, so nothing here reads as overtuned under the new field either).
# local_clergy_max_literacy is listed FIRST wherever it is still present -
# EXPERIMENTAL, unconfirmed: the compact province-panel badge for a
# location modifier appears to be derived from one of its fields (no
# icon field exists anywhere in modifier_type_definitions or any base
# static_modifiers file), and this field's icon (no
# local_clergy_max_literacy.dds, but global_clergy_max_literacy.dds DOES
# exist under gfx/interface/icons/modifier_types/ - a local -> global
# fallback) is the clergy-themed one available. If field order is not
# actually what drives the badge pick, this is a no-op (order never
# affects the modifier's actual effect).
# =====================================================================

# ---------------------------------------------------------------------
# STATE
# ---------------------------------------------------------------------

# Ḥanafī - empire administrator school (Abbasid/Seljuk/Ottoman kanun):
# istihsan-driven administration over hadith-exhaustive jurisprudence,
# so literacy drops far below the class default (and the heretic-
# conversion field is dropped entirely - a pragmatic administrator
# school, not a missionary one).
z_aqd_halqa_state_hanafi = {
	game_data = { category = location }
	local_clergy_max_literacy = 1
	local_monthly_control = 0.05
	local_unrest = -0.03
}
# Ḥanbalī - the Miḥna precedent, assertive under full state authority:
# a much stronger heretic-conversion push, but less calming than the
# default (strict enforcement, not soft administration).
z_aqd_halqa_state_hanbali = {
	game_data = { category = location }
	local_clergy_max_literacy = 3
	local_monthly_control = 0.05
	local_heretic_pop_conversion_speed_modifier = 0.3
	local_unrest = -0.02
}
# Mālikī - law as lived local custom: strong cultural influence, default calm,
# plus local_tribal_promotion (moved here from Shāfiʿī - Mālik's own
# Medinan-custom/Bedouin-law roots fit tribal settlement at least as well)
# and a steady local_monthly_development trickle from a stable, custom-
# rooted seat of jurisprudence.
z_aqd_halqa_state_maliki = {
	game_data = { category = location }
	local_clergy_max_literacy = 3
	local_monthly_control = 0.05
	local_cultural_influence = 0.5
	local_tribal_promotion = 0.1
	local_monthly_development = 0.0050
	local_heretic_pop_conversion_speed_modifier = 0.15
	local_unrest = -0.03
}
# Shāfiʿī - the methodologist's school: very strong literacy (both the
# flat local_clergy_max_literacy and a local_max_literacy percentage
# uplift for the wider populace) plus local_trade_center_power (the
# Shāfiʿī-dominant Indian Ocean/Swahili/Malabar trade networks) - and NO
# control field at all, not even reduced: the same hadith-exhaustive
# rigor that makes its jurisprudence so respected leaves it with no
# administrative edge whatsoever next to Ḥanafī's pragmatic istihsan (a
# real, often-discussed tension between the two largest Sunnī schools).
# local_tribal_promotion moved to Mālikī (see above).
z_aqd_halqa_state_shafii = {
	game_data = { category = location }
	local_clergy_max_literacy = 10
	local_max_literacy = 3
	local_trade_center_power = 0.10
	local_heretic_pop_conversion_speed_modifier = 0.15
	local_unrest = -0.03
}
# Ẓāhirī - demographic rather than administrative footprint; no unrest
# field at all (certainty of unambiguous ruling draws settlers, but
# Ẓāhirī's confrontational, polemical style - Ibn Ḥazm's own reputation -
# means the circle does nothing to actually calm the province).
z_aqd_halqa_state_zahiri = {
	game_data = { category = location }
	local_clergy_max_literacy = 3
	local_monthly_control = 0.05
	local_migration_attraction = 0.05
	local_population_growth = 0.01
	local_heretic_pop_conversion_speed_modifier = 0.15
}
# Ismāʿīlī - Fatimid/Nizari fortress statecraft (Alamut): doubled
# heretic-conversion push (the daʿwa) and a strong defensiveness bonus.
# Literacy dropped to a token 0.5 even here - the daʿwa's hierarchy runs
# on initiatory secrecy, not an open madrasa system, so formal clergy
# literacy barely moves even where the school IS the state religion.
z_aqd_halqa_state_ismaili = {
	game_data = { category = location }
	local_clergy_max_literacy = 1
	local_monthly_control = 0.05
	local_defensive = 0.25
    local_heretic_pop_conversion_speed_modifier = 0.3
	local_unrest = -0.03
}
# Jaʿfarī - the marjaʿiyya's scholarly apparatus: by far the strongest
# clergy literacy of any madhhab/class (flat AND percentage), backed by
# local_clergy_estate_power (the clerical estate's institutional weight)
# and local_clergy_food_consumption (a large, well-supported seminary
# population) - but the hawza's independence from state administration
# means it actively works against central control rather than merely
# failing to help it.
z_aqd_halqa_state_jafari = {
	game_data = { category = location }
	local_clergy_max_literacy = 10
	local_max_literacy = 3
	local_monthly_control = -0.05
	local_clergy_estate_power = 0.5
	local_clergy_food_consumption = 0.1
	local_heretic_pop_conversion_speed_modifier = 0.15
	local_unrest = -0.05
}
# Zaydī - imamate martial tradition: manpower, at the cost of a weaker
# heretic-conversion push than the default (soft power traded for hard).
z_aqd_halqa_state_zaidi = {
	game_data = { category = location }
	local_clergy_max_literacy = 3
	local_monthly_control = 0.05
	local_levy_size_modifier = 0.1
	local_manpower_modifier = 0.02	
	local_heretic_pop_conversion_speed_modifier = 0.1
	local_unrest = -0.03

# Ibāḍī - unchanged from the class baseline.

	game_data = { category = location }
	local_clergy_max_literacy = 3
