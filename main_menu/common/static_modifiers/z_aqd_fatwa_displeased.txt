# =====================================================================
# AQIDAH SCHOOLS OF CREED - "Local <Madhhab> Jurists Displeased".
#
# Applied by scripted_effects/z_aqd_fatwa_effects.txt's
# aqd_fatwa_apply_displeased_for_seat when the ruler refuses a fatwa
# demanding peace in an unjust war against a fellow-sect, aqidah-
# acceptable Muslim state (events/religion/z_aqd_fatwa_events.txt).
#
# NINE concrete objects, one per madhhab - a province can hold seats of
# more than one madhhab, and only the madhhab whose own jurists issued
# (and were refused) the fatwa should have its ḥalqa eligibility
# blocked; the other seat(s) in the same province must keep rolling
# normally. Each now has its OWN madhhab name in both display name and
# desc (main_menu/localization/english/aqd_l_english.yml - "Local <X>
# Jurists Displeased", e.g. "Local Ḥanafī Jurists Displeased") rather
# than all nine sharing one generic "Local Jurists Displeased" string -
# mirrors z_aqd_fatwa_of_jihad.txt's own flavorizing pass. The
# MECHANICAL reason for nine separate keys is unchanged either way and
# would hold even without the name change: multiple of these can be
# simultaneously active in the same province (different locations, or
# even the same location if it hosts more than one seat) - see
# aqd_fatwa_apply_displeased_for_seat's own header for why that's
# always scoped to exactly one (location, madhhab) pair at a time.
#
# scripted_triggers/z_aqd_jurist_triggers.txt's 9 concrete
# aqd_halqa_prov_ready_<madhhab> triggers each check for their OWN
# matching key here to gate that one madhhab's ḥalqa eligibility,
# alongside that same madhhab's own three ḥalqa-class keys (static_
# modifiers/z_aqd_halqa.txt) - the old realm-wide aqd_location_has_
# active_halqa umbrella this comment used to reference was removed
# entirely (folded per-madhhab into aqd_halqa_prov_ready_<X> itself, so
# a different madhhab's seat in the same province can run its own
# ḥalqa in parallel instead of being blocked by this one).
#
# Calibration: local_unrest = 0.5 matches the highest flat-unrest
# modifier found anywhere in the base game (cruel_overlord,
# main_menu/common/static_modifiers/location.txt) - deliberately at
# that ceiling rather than below this mod's own 0.4
# z_aqd_jurist_evicted, since a fatwa publicly condemning an ongoing
# unjust war, refused, reads as at least as severe as "cruel overlord".
# local_production_efficiency = -0.10 matches the base game's own
# largest named production-penalty tier
# (large_production_efficiency_penalty). No decaying = yes - matches
# z_aqd_jurist_evicted's non-tapering design; the displeasure holds at
# full strength until the term ends (5 years at stage 1, re-extended to
# 10 for every affected seat if stage 2 is also refused).
# =====================================================================
